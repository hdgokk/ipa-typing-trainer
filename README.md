# IPA 输入法学习 · 工作台

一个 IPA（国际音标）学习与打字训练工具。纯单文件 HTML 应用，无需安装、无需联网，浏览器打开即用。

## 功能

- **课程化学习**：按音标分类分课，逐步掌握 IPA 符号的输入
- **打字练习**：跟随课程进行音标字符的听打/看打训练
- **实时进度**：左侧目录展示学习进度，右侧辅助面板提供提示
- **自由练习模式**：不按课程，自由输入练习任意音标

## 使用方法

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建步骤。

## 技术说明

- 单文件实现（HTML + CSS + JavaScript），约 110KB
- 依赖 IPA 显示字体（IPAPANNEW / Doulos SIL / Charis SIL，按序回退）
- 支持浅色主题，适配 macOS / Windows / Linux 现代浏览器
